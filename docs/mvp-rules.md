# ResaleIQ MVP Rules

## Core Product

ResaleIQ is an Inventory Recovery Intelligence tool.

Primary workflow:
upload → analyze → prioritize → recover

---

# Non-Negotiable Rules

1. No fake tabs
2. No dead routes
3. No fake AI claims
4. No placeholder modules
5. No feature bloat
6. No marketplace APIs yet
7. No OCR/image AI yet
8. No crosslisting engine
9. No enterprise dashboard ecosystem
10. No feature added unless it strengthens the recovery workflow

---

# MVP Priorities

## Tier 1
- inventory upload
- parsing
- recovery analysis
- recommendation quality
- prioritization
- operational trust

## Tier 2
- onboarding polish
- exports
- lead capture
- sample reports

## Tier 3
- future intelligence
- monitoring
- automation
- integrations

---

# Product Philosophy

Recommendation usefulness matters more than technical sophistication.

Operational trust matters more than feature quantity.

The goal is:
- believable recovery analysis
- actionable recommendations
- repeated usage behavior

Not:
- flashy dashboards
- fake automation
- AI hype

---

# Every Screen Must Support

upload → analyze → prioritize → recover

If a screen does not support this workflow:
question whether it should exist.
